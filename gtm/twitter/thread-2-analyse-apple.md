## Tweet 3/10

3/10 -- Le moteur de croissance : les Services 🚀

Le hardware plafonne. Mais les Services (App Store, iCloud, Apple TV+, Apple Pay) explosent :

- Croissance : ~15%/an
- Marge brute Services : >70% (vs ~37% pour les produits)
- Deja ~25% du CA total

C'est la ou le marche met la prime. ↓

## Tweet 5/10

5/10 -- Le Bull Case 🐂

Si les Services accelerent a 20%/an et que les marges grimpent :

- Croissance FCF : 12% (annees 1-5)
- Marge FCF : 32%
- Vision Pro / IA generative = nouveaux relais

→ Valeur intrinseque : ~210 $ par action (+27%)

Le marche parie sur ce scenario. ↓

## Tweet 6/10

6/10 -- Le Bear Case 🐻

Si l'iPhone decline, la Chine se complique, et la reglementation frappe :

- Croissance FCF : 3% seulement
- Pression sur les marges (App Store, antitrust EU)
- Multiple de valorisation se comprime

→ Valeur intrinseque : ~120 $ par action (-27%)

Pas impossible du tout. ↓

## Tweet 9/10

9/10 -- Mon verdict sur AAPL ⚖️

Au cours actuel (~190 $), Apple est probablement a sa juste valeur, voire legerement surcotee.

- Upside dans le bull case : +10-15%
- Downside dans le bear case : -30-35%

Pas un mauvais business. Mais pas une affaire non plus a ce prix. ↓
